## Overview
`tcpdump` captures and shows live traffic on network interfaces.

## Usage
- Verify packets arrive
- Capture DNS
- Capture HTTP
- Capture SSH

## Common Syntax
`sudo tcpdump`  
`sudo tcpdump -i eth0`  
`sudo tcpdump port 443`  
`sudo tcpdump host 192.168.1.25`  

## Output
- Explain
- Source
- Destination
- Flags
- Length

## Practical Examples
DNS query
TCP handshake
HTTP request

## Troubleshooting
Packets never arrive

Wrong interface
Firewall
